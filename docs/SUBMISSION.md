# Distribution and Submission

Primary distribution is the public `echoomegaprime/echo-fleet-roles` repository with immutable GitHub releases. The Codex bundle follows the current local marketplace and plugin packaging contracts. The Claude Code bundle is a compatibility distribution from the same exact commit.

No ChatGPT MCP app, OAuth connection, `.app.json`, public MCP endpoint, or custom UI is part of this product. OpenAI public directory submission is therefore not claimed. If the skills-only bundle is later submitted to the universal plugin directory, that will be a separate reviewed release using the then-current portal and organization requirements.
