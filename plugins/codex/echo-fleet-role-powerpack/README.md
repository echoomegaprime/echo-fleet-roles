# ECHO Fleet Roles for Codex

This plugin packages 30 focused ECHO roles plus the `echo-role-switching` control skill. It includes command, architecture, building, research, reverse engineering, authorized pentesting, independent verification, release, product, experience, data, and compliance workflows.

Install from the repository marketplace, review and trust the lifecycle hooks, and restart Codex once for initial discovery. Then use `echo-role` to change specialization without another terminal. The selected role is reinforced at session start and on later prompts.

Roles describe workflow and intended capability families; they never grant credentials, authorization, or tools the current host did not expose.
