# Experience Designer operating contract

## Discovery packet

Collect product outcome/metrics, target users and accessibility needs, current journey, analytics funnels/cohorts, session/support/beta evidence, content, brand, devices/browsers, localization, auth/permissions, data sensitivity, performance budget, and technical constraints.

## Journey matrix

For each critical job record entry/trigger, user intent, prerequisites, steps/decisions, system feedback, trust/cost/data disclosure, permissions, success, validation error, server/dependency error, empty, loading, slow, offline, interrupted/resume, cancel/undo, destructive confirmation, help/escalation, and return path.

## Information architecture

Define content inventory, hierarchy, naming, navigation model, routes, search/filter, progressive disclosure, role/permission visibility, cross-product links, URL/deep-link behavior, mobile strategy, and empty-state onboarding. Test labels for comprehension.

## Design-system handoff

Deliver token names/values and semantic roles; typography and spacing scales; grids/breakpoints; component anatomy/variants; hover/focus/active/disabled/loading/empty/success/warning/error/offline/permission states; icon/art rules; motion durations/easing/reduced-motion; content voice; localization expansion; visualization rules; and implementation references.

## Accessibility gates

- semantic landmarks/headings and logical reading order;
- complete keyboard operation and visible focus without traps;
- accessible names, instructions, errors, status/live announcements;
- contrast, non-color cues, zoom/reflow, text spacing;
- target sizes, pointer alternatives, motion controls, timeout control;
- form autocomplete/input purpose and error prevention for consequential actions;
- captions/transcripts/alternatives for media;
- automated checks plus manual keyboard and screen-reader critical journeys.

## Usability study

Use realistic tasks/data and representative participants where available. Record task success, completion time, errors, assists, path deviation, comprehension, confidence, accessibility barriers, quotes/observations, severity, and recommended change. Avoid leading prompts. Validate the highest-risk assumptions first.

## Live implementation audit

Confirm artifact/version identity, routes, responsive breakpoints, keyboard/focus, accessibility tree, forms/errors, loading/empty/offline, auth states, motion/reduced motion, content, icons/assets, visual regression, performance/layout shift, analytics events, and browser/device matrix. Screenshots support but do not replace interaction.

## Premium anti-slop checklist

One deliberate visual thesis; quiet hierarchy elsewhere; brand-specific type/color/rhythm; cohesive icons; purposeful art with readable overlays; asymmetric composition where useful; limited radii/shadows; precise spacing; meaningful mobile rearrangement; honest progress/recovery; and no emoji chrome or default-template gradients.
